DASHBOARD INTERACTIVO DE ARBORIZACIÓN - SERPAR LIMA

Contenido:
- streamlit_app.py: aplicación Python Streamlit.
- requirements.txt: dependencias.
- .streamlit/config.toml: tema pastel de Streamlit.
- datos/programa_arborizacion.csv
- datos/distribucion_distritos.csv

Ejecución desde Anaconda Prompt:

1. Entra a la carpeta del proyecto:
   cd ruta\Arborizacion_SERPAR_Interactivo

2. Instala dependencias:
   pip install -r requirements.txt

3. Inicia la aplicación:
   streamlit run streamlit_app.py

Interactividad:
- Filtros globales por año, mes y distrito.
- Pestañas Resumen, Años y meses, Distritos y Datos.
- Selector de tipo de gráfico anual y mensual.
- Ranking distrital configurable.
- Gráficos Plotly con zoom, desplazamiento y detalles al pasar el cursor.
- Comparación mensual de hasta 6 distritos.
- Búsqueda y descarga de tablas filtradas.
- Carga opcional de nuevos CSV desde la barra lateral.

No utiliza HTML ni JavaScript para construir la interfaz; la aplicación está hecha con Python y componentes de Streamlit.

FONDO: verde pastel uniforme (#F2F7F0). Paneles: verde pastel suave (#EAF2E8).
